# Kakao Map

- https://developers.kakao.com/
- 참조 : https://velog.io/@tpgus758/React에서-Kakao-map-API-사용하기

## 1. API 신청하기

- 환경설정 내용
- .env

```
REACT_APP_KAKAO_MAP_REST_API_KEY=키값
REACT_APP_KAKAO_MAP_JS_API_KEY=키값
```

- Web 플랫폼 설정

- http://localhost:3000
- http://localhost:5173

## 2. 카카오 지도 가이드
